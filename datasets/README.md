# Datasets (WS-24)

Data is stored privately (team drive), never in Git. This folder holds only scripts, guidelines and manifests.

- Egyptian street video (daylight first, then low light), recorded with the chest mount
- Signs, menus and medicine boxes (OCR test set, with ground-truth transcripts)
- EGP banknotes (printed copies and real notes if available; real-note photos never published)
- Volunteer faces (written consent only; embeddings, never published)
- Street-noise and spoken-command audio (wake word and STT tests)

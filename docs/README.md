# Documentation index

Start here. Every new doc should begin from one of the templates below.

## Templates

| Template | Use it for |
| --- | --- |
| [README template](templates/readme-template.md) | A module or folder README |
| [Runbook template](templates/runbook-template.md) | Repeatable procedures (dev setup, sideload, demo day, release) |
| [Decision template](templates/decision-template.md) | A Technical Decision, saved in `decisions/` |
| [Test report template](templates/test-report-template.md) | Test and field-test results with evidence |

Rules: no secrets, personal data, face data or recordings in docs. Use the templates for all new docs.
